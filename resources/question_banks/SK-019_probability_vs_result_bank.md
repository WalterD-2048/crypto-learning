# SK-019 题库：概率思维 vs 结果导向

> 用途：训练学习者把 `决策质量` 和 `结果质量` 拆开看。默认覆盖 `辨析 / 直接应用 / 反例构造 / 案例判断`。
> 判定原则：答案必须先回到决策时刻的信息集。

---

## 建议起手顺序

1. 辨析
2. 直接应用
3. 案例判断
4. 反例构造

---

## 标准题单（10题）

### 第1题
- 题型：辨析
- 题目：`赚钱` 是否足以证明一笔交易是好决策。
- 评分要点：
  - 不足以。
  - 赚钱只说明路径有利，不自动说明结构正确。

### 第2题
- 题型：辨析
- 题目：`好决策亏钱` 和 `坏决策赚钱` 哪个更危险，为什么。
- 评分要点：
  - 坏决策赚钱更危险。
  - 它会强化错误习惯。

### 第3题
- 题型：直接应用
- 题目：一笔单严格按计划止损 1R，另一笔无计划冲动追单赚 2R。哪笔决策质量更高。
- 评分要点：
  - 前者更高。
  - 必须回到计划、风险和纪律。

### 第4题
- 题型：案例判断
- 题目：为什么交易系统最怕“侥幸成功”，而不只是“计划内亏损”。
- 评分要点：
  - 侥幸成功会污染反馈回路。
  - 会让学习者错把运气当能力。

### 第5题
- 题型：辨析
- 题目：`结果不好` 和 `决策不好` 的区别是什么。
- 评分要点：
  - 结果不好可能只是路径不利。
  - 决策不好是信息、逻辑、风险或纪律有结构性缺陷。

### 第6题
- 题型：反例构造
- 题目：构造一个“坏决策赚钱”的例子。
- 评分要点：
  - 必须体现没有计划或违规执行。
  - 必须说明为什么结果好不洗白结构差。

### 第7题
- 题型：案例判断
- 题目：连续两笔好决策亏损后，最容易出现什么错误动作。
- 评分要点：
  - 临时改规则。
  - 追求立刻扳回。
  - 用结果否定方法。

### 第8题
- 题型：直接应用
- 题目：复盘时第一步应该先看什么。
- 评分要点：
  - 先看决策时刻的信息、计划和风险定义。
  - 不是先看最终赚亏。

### 第9题
- 题型：辨析
- 题目：为什么“市场已经证明我对”这句话通常不严谨。
- 评分要点：
  - 市场只给出结果，不直接证明结构质量。
  - 结果中混有路径和运气。

### 第10题
- 题型：案例判断
- 题目：用不超过 3 句话解释，为什么概率思维是交易生存的底层前提。
- 评分要点：
  - 好决策不保证单次成功。
  - 需要长期样本而非单次结果。
  - 风险管理和纪律必须先于结果评价。

---

## 评分 rubric

- `满分`：始终回到决策时刻的信息集，能清楚分离结构与路径。
- `部分得分`：知道“赚钱不等于做对”，但不能稳定说明为什么。
- `不通过`：仍然以盈亏结果直接评价决策质量。

---

## 常见误答

- “赚了就是好决策。”
- “亏了就说明策略有问题。”
- “市场后面按我想的走了，所以我当时一定做对了。”
