# SK-031 ~ SK-042 题库：链上指标与周期读法

> 用途：覆盖链上数据边界、Realized Cap、MVRV、MVRV-Z、NUPL、SOPR、LTH/STH、三指标联合读法与周期复盘。
> 判定原则：答案必须区分“指标读数”与“交易结论”，不允许单指标直接下结论。

---

## 标准题单（12题）

### 第1题
- 题型：辨析
- 题目：链上数据能测量什么，不能测量什么。
- 评分要点：能测链上转移和成本基础；不能完整测 CEX 内部账、场外交易和未上链意图。

### 第2题
- 题型：直接应用
- 题目：Realized Cap 为什么不是简单的当前价格乘供应量。
- 评分要点：每枚币按最后移动时价格计价，反映链上成本基础。

### 第3题
- 题型：辨析
- 题目：Market Cap 和 Realized Cap 差值代表什么。
- 评分要点：代表全网未实现盈亏的大致状态，不是可直接兑现的现金。

### 第4题
- 题型：计算题
- 题目：Market Cap 为 1.2T，Realized Cap 为 600B，MVRV 是多少。
- 评分要点：MVRV = 2.0。

### 第5题
- 题型：场景判断
- 题目：MVRV 低于 1 通常说明什么。
- 评分要点：市场价格低于链上成本基础，广泛未实现亏损，可能接近投降区但不能单独判底。

### 第6题
- 题型：辨析
- 题目：MVRV-Z Score 为什么要标准化。
- 评分要点：为了比较偏离历史均值的程度，减少不同周期规模差异。

### 第7题
- 题型：直接应用
- 题目：NUPL 进入欣快区，应该直接做空吗。
- 评分要点：不能直接做空；它提示过热风险，需要结合趋势、资金费率和结构确认。

### 第8题
- 题型：辨析
- 题目：SOPR > 1 和 SOPR < 1 分别代表什么。
- 评分要点：>1 为平均获利卖出，<1 为平均亏损卖出。

### 第9题
- 题型：案例判断
- 题目：为什么牛市中 SOPR 回踩 1.0 可能是支撑，熊市中却可能是阻力。
- 评分要点：牛市成本线附近承接强；熊市反弹到成本线容易被解套卖压压制。

### 第10题
- 题型：直接应用
- 题目：LTH 和 STH 的常用分类门槛是什么，行为差异在哪里。
- 评分要点：155 天；LTH 更偏长期持有，STH 对价格波动更敏感。

### 第11题
- 题型：框架应用
- 题目：MVRV 偏高、NUPL 欣快、SOPR 持续大于 1，如何初步判断周期位置。
- 评分要点：偏过热/顶部风险上升，但需结合价格结构、宏观和资金费率。

### 第12题
- 题型：反例构造
- 题目：构造一个“单一链上指标乐观但不应重仓”的场景。
- 评分要点：必须有其他指标不确认、宏观或技术结构冲突、流动性风险等。

---

## 评分 rubric

- `满分`：能解释指标定义、读数含义、适用边界和联合判断。
- `部分得分`：会背定义，但不能说明失效场景。
- `不通过`：把某个指标当作买卖信号本身。

## 关键技能错因与补救方向

| 技能 | 错因 | 常见表现 | 补救 |
|------|------|----------|------|
| SK-031 | 概念混淆 | 把链上数据当成全市场数据，忽略 CEX/OTC/未上链行为 | 先列“能测什么 / 不能测什么”两栏。 |
| SK-031 | 边界遗漏 | 用链上转账数量直接解释价格方向 | 补 CEX 内部账和场外交易反例。 |
| SK-032 | 概念混淆 | 把 Realized Cap 当作 Market Cap 的平滑版本 | 重写每枚币按最后移动价格计价的定义。 |
| SK-032 | 推导断链 | 不会从 UTXO 成本基础推到全网持仓成本 | 先画 UTXO 最后移动价格 -> 成本基础 -> 聚合估值。 |
| SK-033 | 概念混淆 | 把 Market Cap - Realized Cap 当成可兑现现金 | 改为“未实现盈亏压力”的近似状态。 |
| SK-033 | 边界遗漏 | 忽略沉睡币、丢失币和交易所内转账造成的偏差 | 补数据局限题。 |
| SK-034 | 概念混淆 | 只会背 MVRV = Market Cap / Realized Cap，不懂成本基础含义 | 先解释 Realized Cap，再解释比值。 |
| SK-034 | 应用偏差 | MVRV 高就立刻做空，MVRV 低就立刻抄底 | 补“指标只提示风险区间，还需结构/宏观/资金费率确认”的场景题。 |
| SK-034 | 边界遗漏 | 忽略 CEX、OTC、宏观冲击和周期 regime | 构造单一指标失效反例。 |
| SK-034 | 推导断链 | 不能从比值变化推到未实现盈亏和情绪状态 | 强制写出 `市值偏离成本基础 -> 盈亏状态 -> 行为压力`。 |
| SK-035 | 计算/统计误读 | 把 Z-score 极值当成必然顶部/底部 | 补标准化含义、历史样本和 regime 变化边界。 |
| SK-035 | 应用偏差 | 看到 >7 或 <0 就直接做交易 | 改写成风险区间判断，再要求结构确认。 |
| SK-036 | 概念混淆 | 只背 NUPL 五区间，不懂未实现盈亏分布 | 先用 Market Cap、Realized Cap 和 NUPL 公式重建。 |
| SK-036 | 结果倒推 | 事后把欣快区等同精确卖点 | 补“欣快后继续上涨”和“未到欣快先反转”反例。 |
| SK-037 | 概念混淆 | 不区分卖出价/买入价与日内价格涨跌 | 先写 SOPR = realized value / cost basis。 |
| SK-037 | 边界遗漏 | 忽略短持、内部转账和噪音对 raw SOPR 的影响 | 补 aSOPR 与过滤边界。 |
| SK-038 | 应用偏差 | 不区分牛市/熊市 regime，机械读 SOPR=1 | 每题先判断 regime，再解释 1.0 是支撑还是阻力。 |
| SK-038 | 推导断链 | 不会说明为什么同一数值在不同周期含义相反 | 写出持有者成本线、解套卖压和承接强弱。 |
| SK-039 | 基础记忆缺失 | 忘记 155 天分类门槛 | 做 LTH/STH 定义短练。 |
| SK-039 | 应用偏差 | 把 LTH 卖出一概看成利空 | 区分早期分发、顶部派发和再积累。 |
| SK-040 | 框架纪律 | 三指标只挑一个支持自己观点 | 必须三指标各写读数、含义、冲突和权重。 |
| SK-040 | 边界遗漏 | 指标一致就直接下交易结论 | 加宏观、资金费率和技术结构确认。 |
| SK-041 | 批判不足 | 只会用指标，不会质疑指标失真 | 每题必须列一个数据污染来源。 |
| SK-041 | 概念混淆 | 把链上透明等同数据无偏 | 补交易所内部账、混币、沉睡币、标签错误反例。 |
| SK-042 | 结果倒推 | 用已知顶部/底部解释指标，而不是按当时数据判断 | 先遮住后续价格路径，只用当时指标定位。 |
| SK-042 | 推导断链 | 不能把 2020-2022 各节点和指标状态连起来 | 做时间点 -> 指标读数 -> 周期判断 -> 边界的四列表。 |
