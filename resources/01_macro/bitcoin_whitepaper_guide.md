## 第一节：问题陈述（Introduction）

**现状的缺陷：**
- 线上支付依赖金融机构作为可信第三方
- 第三方必须介入调解纠纷 → 交易不可逆
- 不可逆性带来欺诈成本 → 需要更多信任 → 提高了交易门槛
- 小额支付在经济上不可行（手续费>金额）

**Satoshi 的方案：**
> "What is needed is an electronic payment system based on cryptographic proof instead of trust, allowing any two willing parties to transact directly with each other without the need for a trusted third party."

用密码学证明替代信任 → 两方可直接交易 → 无需银行或任何中介。

---

## 第二节：交易的定义

比特币不是"存储在某个地方的文件"，而是**一条电子签名链**：

```
Alice → [用私钥签名] → Bob → [用私钥签名] → Carol
```

每次转账，发送方用私钥对"上一笔交易哈希 + 接收方公钥"进行签名。
任何人都可以用公钥验证签名是否有效。

**核心问题（双花）：**
Bob 无法验证 Alice 是否已将同一枚比特币发给了其他人。
传统方案：依赖中央机构（银行）维护账本，确保每笔钱只花一次。
Satoshi 的方案：去中心化的分布式账本（区块链）。

---

## 第三-四节：时间戳服务器 + 工作量证明

**时间戳服务器：** 对一批交易（区块）进行哈希，广播到全网。每个区块包含前一个区块的哈希 → 形成链式结构。

**工作量证明（Proof-of-Work）：**
- 矿工必须找到一个随机数（nonce），使得区块哈希满足特定条件（前N位为0）
- 这个过程需要大量计算，但验证极其简单
- 最长链代表"消耗了最多工作量"的版本 → 全网以此为准

**安全性来源：**
攻击者要篡改历史交易，需要重算被篡改区块后的所有区块，且速度要超过整个诚实网络。当诚实节点掌握>50%算力时，攻击者成功概率随时间指数级递减。

---

## 第五-六节：网络与激励

**节点协作规则：**
1. 新交易广播到全节点
2. 每个节点收集交易到区块
3. 节点工作以找到区块的工作量证明
4. 找到后广播该区块
5. 只有区块内交易都有效才接受
6. 接受后在此区块后继续工作（默认接受为最长链）

**激励机制（为何矿工诚实）：**
- 每个新区块给矿工一定数量的新比特币（区块奖励）
- 矿工若想"双花"攻击，需放弃所有挖矿收益
- 合理的矿工会选择**遵守规则赚取奖励**而非攻击系统
- 随时间推移，区块奖励递减，交易手续费逐渐成为主要激励

## 第七节：Merkle Tree（修剪旧区块）

随着区块链增长，全量存储成本上升。Satoshi 提出用 **Merkle Tree** 结构，使得已经深埋的交易可以被修剪（只保留根哈希），而不破坏链的完整性。

---

## 第九节：UTXO 模型

比特币没有"账户余额"的概念。你的"余额"是所有发给你的**未花费交易输出（UTXO）**的总和。

每笔交易：
- **输入**：引用一组 UTXO（证明你有权花费）
- **输出**：创建新的 UTXO（发给收款方 + 找零给自己）

这使得比特币可以在不追踪账户状态的情况下验证所有权。

---

## 第十节：隐私模型

比特币的隐私不依赖于"身份保密"，而是依赖于**公钥匿名**：

```
传统银行：身份 ↔ 账户（金融机构知道所有信息）
比特币：  公钥 ↔ 交易（所有人可见，但公钥不关联真实身份）
```

每次交易建议使用新的密钥对，以避免多笔交易被关联到同一所有者。

---

## 第十一节：攻击概率计算

攻击者落后 z 个区块的情况下追上诚实链的概率：

$$P = 1 - \sum_{k=0}^{z} \frac{\lambda^k e^{-\lambda}}{k!} \left(1 - \left(\frac{q}{p}\right)^{z-k}\right)$$

其中：p = 诚实节点算力比例，q = 攻击者算力比例，λ = 攻击者期望进展

**结论：** 当 q < 0.5 时，攻击者成功概率随 z 增大指数级趋向于0。等待6个确认（约1小时）对于大多数交易已足够安全。

## 核心结论

> "We have proposed a system for electronic transactions without relying on trust."

比特币通过以下机制解决了无需信任的电子支付问题：
1. **数字签名**：证明所有权
2. **区块链 + 工作量证明**：防止双花，建立不可篡改的历史
3. **激励机制**：使诚实行为成为理性选择
4. **去中心化**：无单点故障，无需依赖任何机构
