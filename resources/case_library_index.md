# 概念课案例库索引

> 用途：给概念课提供一组可复用的历史事件切片入口。
> 使用方式：先在 `teacher/session_briefing.md` 看具体技能点的“建议案例强度”和三层切片，再回到这里找更完整的案例池。
> 已落地的完整案例档案位于 `resources/cases/`，可直接拿来上课；优先按 dossier 内的“原始证据包”准备截面与时间线。

## 主线A：货币 / 宏观 / 周期

  已落地 dossier：`resources/cases/1971-08_nixon_shock_dossier.md`
- `二战战俘营香烟货币`
  适合：SK-001、SK-002

- `塞浦路斯银行危机与资本管制`
  适合：SK-001 ~ SK-005

  重点：货币扩张、资产先涨、购买力传导、风险资产相关性。

## 使用建议

1. 首次进入新技能点，默认从 `入门切片` 开始。
2. 若学习者已经能说出原则但迁移不稳，切到 `标准切片`。
3. 若连续卡在边界、反例或高压场景，直接上 `高压反例切片`。
4. 每次概念课只选 1 个核心事件，不要把案例库当时间线讲义。
