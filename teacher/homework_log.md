# 学习记录（homework_log.md）

> 本文件记录练习课、延迟验证、间隔复习，以及为还原学习轨迹而插入的概念重修记录。
> 同一天、同一技能点的记录必须按真实发生顺序排列。
> 可运行 `python3 tools/learning_state.py sync` 归一化顺序并刷新依赖它的汇总文件。

## 记录格式

默认记录格式如下。概念重修、延迟验证和间隔复习也在本文件中按同样的时间顺序追加：

```markdown
### [日期] 练习课：SK-XXX《[技能点名称]》

**Shaw 出题清单：**
| 编号 | 题库题号 | 题目简述 | 题型 | 来源技能点 | 结果 |
|------|---------|---------|------|-----------|------|
| 1 | QB-SK-XXX-01 | [简述] | 计算题 | SK-XXX | ✓ |
| 2 | QB-SK-XXX-02 | [简述] | 场景判断 | SK-XXX | ✗ |
| ... | | | | | |

**题库来源**：[题库路径；如临场生成则写“自拟”]
**使用资源段落**：[guide/dossier 小节；如无则写“—”]
**使用图示**：[图示编号或小节名；如无则写“—”]
**本次准确率**：[X]/10（[%]）
**掌握判定**：✅ 已掌握 / ❌ 未掌握
**薄弱题型（如有）**：[列出答错的题型]
**错误模式（如有）**：[Root 分类：叙事替代推理 / 结果倒推 / 概念混淆 / 推导断链 / 应用偏差 / 边界遗漏 / 计算错误]

**下次复习到期**：[日期]（如已掌握）
```

延迟验证建议使用如下标题格式：

```markdown
### [日期] 延迟验证：SK-XXX《[技能点名称]》
```

概念课（或概念重修）建议使用如下结构：

```markdown
### [日期] 概念课：SK-XXX《[技能点名称]》

**案例 dossier**：[对应 dossier 路径；若未建档则写“未建档：xxx”]
**案例切片**：[本次使用的切片名 / 事件名]
**资源段落**：[实际使用的 guide/dossier 小节，便于后续统计内容效果]
**证据包条目**：[实际使用的价格截面 / 链上读数 / 时间线 / 盘口条件]
**图示编号**：[实际使用的图示小节或编号；如无则写“—”]
**盛言开场案例**：[历史事件 / 当下切片]
**当时已知信息**：[学习者开场时允许看到的信息]
**当时未知信息**：[此时刻不能提前揭示的结果]
**学习者当下判断**：[在没看结果前给出的第一版解释]
**结果揭示**：[何时揭示后续发生了什么，以及揭示方式]
**偏差复盘**：[学习者最容易出现的判断偏差]
**复述检验**：[学习者最终用 1-3 句话复述出的原则]

[可选字段]
**核心教学方法**：[如本节新增了判断清单 / 两步法 / 层级模型]
**关键辨析突破**：[本节最重要的边界辨析]
**框架边界**：[原则何时不成立，或不该被过度外推]
**Root 延伸**：[Root 的补充追问或延伸反例]
**盛言收尾评注**：[盛言最后一句评价]
```

**盛言开场案例**：1933年罗斯福第6102号行政令——禁止私人持有黄金
**当时已知信息**：黄金的物理数量没有突然变化，但私人持有、运输和交易都受到了制度限制。
**当时未知信息**：最先受损的是哪条货币属性，以及为什么制度变化不等于稀缺性变化。
**学习者当下判断**：私人不能自由持有和流通黄金时，最先受损的是便携性，而不是稀缺性；制度限制改变的是使用门槛，不是物理供给。
**结果揭示**：先用黄金禁令锁定“制度限制 vs 供给变化”的区别，再为六条属性各自建立专属判断问题，补强耐久 / 可替换等边界。
**偏差复盘**：最容易把制度性使用限制误判成稀缺性变化，或者把属性全优直接推出“必然成为货币”。
**复述检验**：六属性衡量的是货币技术特征，但货币能否成立还要看共识和接受度；属性全优不等于一定成为货币。
**核心教学方法**：为每条属性建立"专属判断问题"，用场景逐条推导
**六条判断问题**：
- 稀缺性：供给能不能被轻易增加？
- 耐久性：能不能在时间推移中保持自身完整？
- 便携性：能不能低成本地移动它？
- 可分性：能不能按需分割，且分割后总价值不变？
- 可验证性：能不能低成本确认它是真的、足量的？
- 可替换性：每一单位之间是不是被无差别对待？

**关键辨析突破**：耐久 vs 可替换——"东西本身坏了没有？坏了是耐久，没坏但被区别对待是可替换"
**框架边界**：六属性衡量技术特征，但货币成立还需要共识和接受度——属性全优不等于一定成为货币
